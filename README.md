# Umbral

A mobile-first dark investment-terminal prototype. HTML/CSS/JavaScript; open `index.html` directly for the static preview. `optimizador/` is an exact copy of the Sharpe Lab optimizer and its data and solver as fetched from Davizz-dev13/sharpe-lab on 29 September 2026. See SETUP.md for registration deployment and limitations.

This is a prototype with two cited editorial news cards, example decision rules, hypothetical weights and scenario controls. It does **not** provide a live news feed, automated trading signals, forecasts, signup backend, or investor advice yet. Signup is visibly disabled until an owner-controlled Supabase project is configured, privacy notice prepared, and the actual registration/count flow tested.
